# Ian Daniel Grinbank Ferrón | Pantallas LED

Landing page responsive para venta de pantallas LED, con brochure de precios y formulario de contacto funcional mediante `mailto:`.

## Editar contacto

El email de destino está en `script.js`, constante `CONTACT_EMAIL`.

## Publicación

El sitio es estático y funciona directamente con GitHub Pages desde la raíz del repositorio.
